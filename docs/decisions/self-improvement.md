# Self-improvement

The setup improves by retrospectives of past sessions (skill `retro`), not by instructions alone, because those were
already ignored: rules were not loaded, and scripts ran where Edit was asked for. A retrospective finds what cost round
trips and fixes it where it is enforced or said: a hook, a check, a script, a skill, an agreement in `CLAUDE.md`. What
cost them is in the friction log (`docs/decisions/friction-log.md`); what a retrospective decided is in the decision of
its topic.

**Rejected**

- a retrospective after every session (cost without friction)
- a scheduled cloud agent (can't read the local transcripts)
- a file per session for the note about a context summary (the transcript records each summary and each Stop)
